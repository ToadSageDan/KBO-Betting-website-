# KBO Edge — Korean Baseball Betting Analytics

A comprehensive KBO betting analytics site for finding edges on South Korean Baseball games.

## Features

- **Dashboard** — Today's 5 games with moneyline, O/U, spread odds and live weather per stadium
- **Matchup Analyzer** — Deep pitcher vs team analysis with career splits, Last 5/10 toggle, situational splits (home/away/day/night/turf/dome)
- **Pitcher Cards** — Full player cards with 2023–2026 season stats, year selector tabs, vs-team dropdowns, situational splits, ERA progress bars
- **Teams** — All 10 KBO teams with offensive/defensive stats, runs-by-inning bar chart
- **Standings** — Full 2026 standings with GB, PCT, RS/RA, Last 5/10, home/away records
- **Runs Tracker** — Offense/defense rankings, inning-by-inning heatmap table, key batter cards
- **Weather** — Real-time-style weather for all 9 KBO stadiums (temp, humidity, wind, precip %)
- **Betting Tools** — Odds converter (American → decimal/fractional/implied), Kelly Criterion calculator, implied probability grid, O/U quick analyzer

## Usage

Open `index.html` in any modern browser — no server or build step required.

## Data

All 2026 season stats, historical stats (2023–2026), vs-team splits, situational splits, and weather data are included in `data/kbo_data.js`.

Teams: KT Wiz, LG Twins, SSG Landers, NC Dinos, KIA Tigers, Doosan Bears, Hanwha Eagles, Lotte Giants, Samsung Lions, Kiwoom Heroes
